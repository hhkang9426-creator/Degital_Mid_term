1장. 숫자를 상자에 담는 법

컴퓨터는 숫자를 0과 1이 든 칸(비트)에 적어요. 칸이 8개면 256가지 숫자만 적을 수 있어요.

진법: 같은 숫자를 다르게 읽는 법

이름쓰는 글자묶는 법같은 숫자 예 (0111 1111)
Binary 2진수0, 1컴퓨터가 실제로 쓰는 모양0111 1111
Octal 8진수0~7비트를 3개씩 묶기 (001 111 111)177
Decimal 10진수0~9우리가 평소 쓰는 숫자127
Hexadecimal 16진수0~9, A~F비트를 4개씩 묶기 (0111 1111 → 7, F)0x7F

원서는 이 네 가지 이름만 나열해요. 위 표의 설명은 제가 보충했어요.

음수는 "시계"로 생각하세요: 2의 보수

맨 앞 비트가 1이면 음수예요. 8비트 숫자를 256칸짜리 둥근 시계로 그리면 이래요.

+64 + 64 = ?

127을 넘어 시계 반대편으로 넘어가요. 8비트 답은 1000 0000 = -128. 이게 오버플로예요.

0이 하나뿐

+0, -0이 따로 없어요. 덧셈기·곱셈기를 그대로 쓸 수 있는 게 장점이에요.

16비트 표 (표 1.3): 시계가 더 커진 것뿐

원서 표는 -129, -32,767, -32,768의 16진수가 전부 0xFF80으로 잘못 인쇄돼 있어요. 위는 바로잡은 값이에요.

8비트 → 16비트로 늘릴 때는 맨 앞 비트를 왼쪽에 복사해서 붙이면 값이 안 변해요. -2는 0xFE → 0xFFFE.

소수로 쓰면 곱해도 안 넘쳐요 (Q15)

DSP는 곱셈을 엄청 많이 해요. 정수끼리 곱하면 숫자가 빠르게 커져서 상자를 넘치지만, -1~+1 사이 소수끼리 곱하면 항상 작아져요.

0.75
× 0.50
= 0.375 (작아짐, 안 넘침)

정수로 쓰면 24,576 × 16,384 = 402,653,184로 폭발해요. 8비트 소수는 정수 ÷ 128, 16비트 소수(Q15)는 정수 ÷ 32,768이에요.

Q15 × Q15 곱셈 3단계
  1. 16비트 × 16비트 = 32비트가 나와요. 그런데 소수점이 한 칸 밀려서 Q31이 아니라 Q30이에요.
  2. 그래서 왼쪽으로 1비트 밀어요(DSP칩은 자동으로 해줘요).
  3. 위쪽 16비트만 쓰면 다시 Q15예요.

예: 1/2(0x4000) × 1/4(0x2000) = 0x0800 0000 → 한 칸 밀기 0x1000 0000 → 위 16비트 0x1000 = 1/8

부동소수점: 계산기의 과학 표기법

1,200,000 = 1.2 × 106처럼 숫자 부분(가수)과 자리 이동(지수)을 따로 적어요. 아주 작은 수부터 아주 큰 수까지 다룰 수 있는 대신(다이내믹 레인지 큼), 회로가 더 복잡하고 전기도 많이 먹어요.

원서가 적은 지수 바이어스(half 31, double 2047)는 표준과 달라요. 표준은 15, 127, 1023이에요. 수업 자료 기준을 따르세요.

시험에 이렇게 나와요
  • 16비트 표: 0x7FFF = 32,767 / 0xFFFF = -1 / 0x8000 = -32,768
  • binary, decimal, octal, hex 정의와 서로 바꾸기
  • 정수는 곱하면 커지고 소수(Q15)는 작아진다. 그래서 DSP는 소수를 쓴다

2장. 복소수는 "지도 위의 점"이에요

수직선은 한 줄이라 앞뒤로만 가요. DSP는 2차원이 필요해서 동서(실수)와 남북(허수) 두 방향 지도를 써요.

Figure 2.1: I-Q 복소수 평면

2.1 더하기·빼기는 가로끼리, 세로끼리

(3 + j4) − (1 − j6) = 2 + j10: 가로 3−1=2, 세로 4−(−6)=10.
4 · (3 + j4) = 12 + j16: 둘 다 4배.

2.2 곱하기: 늘이고 돌리기

식으로 하면 이렇게 나와요. 시험에 나온다고 하신 부분이에요.

(A + jB)(C + jD) = (AC − BD) + j(BC + AD)

외우는 법: 풀어서 곱하고, j × j = −1을 써서 정리해요. 예: (2+j3)(1−j2) = (2+6) + j(−4+3) = 8 − j

그림으로는 "길이는 곱하고, 각도는 더하기"예요. 그래서 j를 두 번 곱하면 90° + 90° = 180°, 즉 -1이 돼요.

극좌표와 켤레

극좌표

"동쪽 X, 북쪽 Y" 대신 "거리 R, 각도 Ω"로 같은 점을 말해요. 곱셈은 극좌표가 훨씬 쉬워요.

켤레(Z*)

가로축 거울에 비친 점이에요. Z × Z* = R²(실수). 신호의 세기(전력)를 구할 때 써요.

복소 지수: 단위원 위의 점

반지름 1짜리 원 위의 점을 ejΩ라고 써요. 오일러 공식은 "이 점의 가로는 cos, 세로는 sin"이라는 뜻이에요.

ejΩ = cos Ω + j sin Ω   예: ej0 = 1, ej90° = j, ejπ = −1

도(°)와 라디안(π) 바꾸기 (표 2.1)

라디안은 "한 바퀴 = 2π"로 재는 각도예요. 반 바퀴가 π라고 외우면 돼요.

시험에 이렇게 나와요
  • 복소수 정의와 Fig. 2.1 (가로 실수, 세로 허수, Z = X + jY)
  • 덧셈은 성분별로 / 곱셈 (A+jB)(C+jD) = (AC−BD) + j(BC+AD)
  • j² = −1, 극좌표 곱: 크기 곱하기, 각도 더하기

3장. 샘플링: 번쩍이는 불빛으로 보는 세상

ADC는 신호를 "찰칵찰칵" 찍어요. 찍힌 값 하나하나가 샘플이에요. 너무 느리게 찍으면 헛갈려요.

스트로보 불빛이 1초에 8번 번쩍여요(Fs = 8 Hz). 바퀴가 반시계로 f Hz로 돌아요. 번쩍일 때마다 점이 어디 있는지 6번 보여 줘요.

Nyquist 규칙: 신호 속도의 2배보다 빨리 찍어라

파도 모양 신호를 찍어 볼게요. 파란 선이 진짜 신호, 점이 샘플(1초에 8번), 주황 점선은 "컴퓨터가 믿어 버리는 신호"예요.

Nyquist 주파수

= Fs ÷ 2. 신호가 이 속도를 넘으면 안 돼요.

안티에일리어싱 필터

ADC 바로 앞에 아날로그 저역통과 필터를 둬서 너무 빠른 신호를 미리 걸러요.

전화기 예

사람 목소리 최대 약 3600 Hz → 필터로 그 이상을 자르고 → 8000 Hz(8 kSPS)로 샘플링해요. 그래서 배경 음악이 찌그러져 들려요.

양자화: 부드러운 선을 계단으로 바꾸기

ADC는 값을 정해진 계단 높이에 맞춰 "반올림"해요. 계단 높이와의 차이가 양자화 잡음이에요. 비트가 많을수록 계단이 촘촘해요.

그림은 신호가 화면을 꽉 채우도록 확대해서 그렸어요. 그래서 작은 신호일수록 계단이 거칠어 보여요.

3.4 SNR과 dB: "비트 하나 = 6 dB"만 기억하세요

SNR (이상적인 ADC)

SNR(dB) = 6.02 × 비트 수 + 1.76

원서는 8비트 ≈ 48 dB, 12비트 ≈ 72 dB, 16비트 ≈ 96 dB로 써요(대략 6 dB × 비트).

dB 두 가지

전압(진폭): 20 log(V1/V2)
전력: 10 log(P1/P2)

전압은 제곱해야 전력이라 20이 돼요.

상황dB
진폭 2배 (= 디지털 값을 왼쪽으로 1비트 밀기)+6.02 dB ("6 dB/bit")
전력 2배+3.01 dB
전력이 절반 (손실)−3.01 dB
그대로 (이득 1, 증폭기 unity gain)0 dB
시험에 이렇게 나와요
  • sampling, aliasing, Nyquist(Fs/2), quantization, quantization noise의 정의
  • 바퀴 위 점 움직임: 4 Hz에서 방향 모름, 8 Hz에서 멈춘 것처럼, 6~7 Hz에서 거꾸로, 9 Hz = 1 Hz
  • SNR = 6.02N + 1.76, 전압 20 log, 전력 10 log, 비트 하나 = 6 dB

4장. 주파수 응답: 필터는 "체"예요

필터는 신호를 주파수별로 걸러요. 어떤 주파수는 통과시키고 어떤 주파수는 막아요. 새로운 주파수를 만들지는 못하고, 크기와 위상만 바꿔요.

초록색이 통과하는 곳이에요. 가운데(−Fs/2 ~ +Fs/2)만 진짜이고, 좌우 그림은 샘플링 때문에 Fs마다 똑같이 반복되는 모습이에요.

5장. FIR 필터: 이동하는 가중 평균 가장 중요

FIR = Finite Impulse Response. "톡 한 번 치면 응답이 유한하게 끝나는" 필터예요. 곱셈기, 덧셈기, 한 박자 기억(지연 z−1)으로 만들어요.

5.1 구조: 줄 선 숫자들에 점수를 곱해서 더하기

최근 입력 5개에 각각 점수(계수 C)를 곱해서 전부 더하면 출력 하나가 나와요. 다음 박자에는 한 칸 밀어서 또 해요. 이걸 컨볼루션(내적을 한 칸씩 밀기)이라고 해요.

컨볼루션 계산: 직접 밀어 보세요

계수 C = {1, 3, 5, 3, 1}, 입력 x = {−1, 1, 2, 1, 4, −1}(그 밖에는 0). 슬라이더로 k를 옮기면 각 칸에서 x에 C를 곱해 더해요.

임펄스 응답

입력이 "1이 딱 한 번"이면 출력은 계수 그대로 {1, 3, 5, 3, 1}이에요. 위에서 "톡 한 번만"을 눌러 보세요. 이 출력이 임펄스 응답이고, 길이가 유한해서 FIR이에요.

출력 길이

입력 6개, 필터 5탭이면 0이 아닌 출력은 6+5−1 = 10개(k = 0~9)예요. 예제 답: −1, −2, 0, 9, 19, 23, 22, 8, 1, −1.

5.2 이 필터는 무엇을 통과시킬까? (주파수 응답)

생각하기 쉬운 두 가지부터 볼게요.

  • 이동평균(계수가 전부 1): 이웃을 평균 내니까 빨리 흔들리는 건 사라지고 천천히 변하는 것만 남아요 → 저역통과
  • +1, −1, +1, −1…: 천천히 변하는 신호는 이웃끼리 같아서 서로 지워지고, 번갈아 크게 바뀌는 신호는 오히려 커져요 → 고역통과

계수가 주어졌을 때 주파수 ω에서의 이득(몇 배로 키우나)은 이 식 하나로 나와요.

H(ω) = C0 + C1·e−jω + C2·e−j2ω + …

크게 나오면 통과, 0에 가까우면 차단이에요. 5탭 예제 C = {1,3,5,3,1}로 두 점만 계산해 보면 필터 종류를 알 수 있어요.

ω = 0 (DC)

e⁰ = 1이라 그냥 다 더해요: 1+3+5+3+1 = 13

ω = π/2

1·1 + 3·(−j) + 5·(−1) + 3·(j) + 1·1 = −3 → 크기 3 (j끼리 지워져요)

13 → 3으로 줄었으니 저역통과예요. 줄어든 정도는 dB로 20·log(3/13) = −12.7 dB.

5.3 계수 설계: 원하는 모양에서 거꾸로 계수 만들기

"이런 응답이 나오게 해 주세요"(D(ω))라는 주문에서 계수를 구해요. 실제 응답 H(ω)와의 오차를 제곱해서 전부 더한 값이 가장 작아지게 만들면 계수가 나와요(푸리에 설계법).

Ci = (1/2π) ∫ D(ω) ejωi dω

이상적인 저역통과(컷오프 π/2)로 계산하면 계수가 sin(πi/2) / (πi) 모양이 돼요. 이걸 sinc 함수(sin x / x)라고 해요. 한 칸 건너 0이고 가운데에서 멀수록 작아져요.

문제: 이상적인 모양은 계수가 무한히 필요해요. 실제로는 잘라서 쓰니까 모양이 무너져요. 그래서 "품질 vs 탭 수(곱셈기 수)"를 맞바꿔야 해요.

5.4 탭 수 효과: 많을수록 칼같아져요

같은 저역통과(컷오프 π/2)를 7, 15, 63, 255탭으로 만든 응답이에요(세로는 dB, 아래로 갈수록 더 많이 막음). 켜고 꺼서 비교해 보세요.

탭이 늘수록 통과 → 차단 경계가 가팔라지고, 경계에서 먼 차단 구간이 더 깊게 내려가요. 원서 그림에서는 255탭이 약 −42 dB, 1023탭이 약 −54 dB(차이 12 dB = 진폭 약 4배 더 작게)예요.

경계 바로 옆의 출렁임은 이렇게 그냥 자르면 안 줄어요. 다음 장 Windowing이 그걸 줄이는 방법이에요.

지연과 선형 위상: 모두 같은 시간만큼 늦게

FIR의 임펄스 응답에서 가장 큰 값(가운데 탭)이 나오는 위치가 지연이에요. 5탭 예제는 {1,3,5,3,1}의 5가 세 번째니까 3샘플 지연이에요. 원서 식: N탭이 홀수면 N/2+1(소수점 버림), 짝수면 N/2+1/2이고, 둘 다 (N+1)/2로 같아요.

계수 번호를 C₀~C₄로 매기든 C₋₂~C₂로 매기든 주파수 응답의 크기는 같아요. 번호를 옮기는 건 그냥 지연이고, 지연은 위상만 바꾸기 때문이에요.
시험에 이렇게 나와요 (5장)
  • yk = Σ Ci xk−i 로 컨볼루션 직접 계산 (칸마다 곱하고 더하고, 풀이 과정까지 쓰기)
  • 임펄스 응답 = 계수. FIR 이름의 이유(유한한 길이)
  • H(ω) = Σ C e−jωi 계산: H(0) = 13, H(π/2) = −3(크기 3), 20 log(3/13) = −12.7 dB
  • 계수 설계 → sinc, 탭이 많을수록 가파르고 차단 깊음(대신 곱셈기 많이)
  • 선형 위상: 모든 주파수에 같은 지연, 위상 왜곡 없음. 5탭이면 지연 3샘플

IIR 필터: FIR에 "메아리"를 더한 것 개념 중요

원서에서는 8장이에요. IIR = Infinite Impulse Response. 출력을 다시 입력 쪽으로 되돌려 보내요(피드백).

극점(pole)

피드백 때문에 특정 주파수에서 "아주 작은 수로 나누는" 효과가 나서 그 주변이 크게 솟아요.

로프 비유: 주파수 응답을 로프라고 하면 극점은 로프를 위로 들어 올리는 손, 영점은 땅에 누르는 납추예요. 둘을 같이 쓰니 응답을 더 급하게 꺾을 수 있지만, 손이 너무 세면(극점이 큼) 불안정해져요.
시험에 이렇게 나와요
  • IIR = FIR + 피드백 (구조 그림, y = C·x − D·y 모양)
  • FIR vs IIR 비교: 위상, 안정성, 임펄스 응답 길이, 필요한 곱셈기 수
  • 왜 IIR을 쓰나: 적은 자원으로 급한 차단, 아날로그 필터(예: 오디오 장비) 대체

아날로그를 디지털 IIR로 옮기는 방법은 쌍선형 변환(bilinear transform)을 쓰고, 이때 생기는 주파수 찌그러짐을 미리 보정하는 것이 프리워핑이에요. 예: Fs = 1000 Hz에서 3 dB 점 100 Hz → 103.4 Hz로 미리 설계, 250 Hz → 318.3 Hz. 사용자 지정 시험 범위에 들어 있는지는 확인하세요.
